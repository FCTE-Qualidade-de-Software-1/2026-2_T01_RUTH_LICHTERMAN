# Fase 1 — Caracterização e Avaliação do Produto
 
Nesta fase, a equipe caracteriza o produto avaliado, define o propósito da avaliação e seleciona as características de qualidade que serão investigadas.
 
## Resumo
 
| | |
| :--- | :--- |
| **Produto avaliado** | BRB Mobilidade, aplicativo móvel (iOS e Android) de acesso aos serviços do Cartão Mobilidade do Distrito Federal |
| **Contexto de uso** | Uso do ônibus (inclusive em terminais) e do metrô (em estações), antes ou depois do embarque. Cartão físico, validadores e Sistema de Bilhetagem Eletrônica entram apenas como contexto complementar |
| **Tipo de produto** | Aplicativo móvel transacional de serviço público, cujo uso envolve dinheiro e dados pessoais |
| **Características avaliadas** | Capacidade de interação, adequação funcional, eficiência de desempenho e confiabilidade (ISO/IEC 25010:2023) |
| **Objetivos de medição** | O1 a O4, um por característica, detalhados na Fase 2 |
