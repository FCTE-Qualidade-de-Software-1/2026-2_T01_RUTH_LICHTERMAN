# Hipóteses

*Nível operacional.* Cada [questão](questoes.md) recebe uma hipótese, isto é, o resultado que a equipe espera encontrar. Os valores das hipóteses correspondem ao nível **Bom** dos [níveis de pontuação](niveis-pontuacao.md), o que facilita confirmar ou refutar cada uma na Fase 4.

| Hipótese | Questão | Resultado esperado | Métricas |
| :--- | :--- | :--- | :--- |
| H1 | Q1 | Pelo menos 85% das tarefas são concluídas sem ajuda, em tempo até 3 vezes o de um usuário experiente | M1, M2 |
| H2 | Q2 | A pontuação SUS é de pelo menos 68 | M3 |
| H3 | Q3 | Pelo menos 70% dos itens do checklist de acessibilidade são atendidos | M4 |
| H4 | Q4 | Até 0,5 erro por tarefa, e pelo menos 80% das entradas inválidas são bloqueadas com mensagem clara | M5, M6 |
| H5 | Q5 | Pelo menos 90% das funções do inventário estão presentes | M7 |
| H6 | Q6 | Pelo menos 95% dos casos de teste são aprovados | M8 |
| H7 | Q7 | No máximo uma divergência no conjunto de conferências | M9 |
| H8 | Q8 | Pelo menos 90% das recargas aparecem no saldo em até 60 s | M10 |
| H9 | Q9 | Tempo médio de até 3 s em Wi-Fi, e a rede limitada multiplica o tempo em no máximo 3 vezes | M11, M12 |
| H10 | Q10 | Pelo menos 70% das falhas provocadas são recuperadas | M13 |
| H11 | Q11 | No máximo 5% das operações terminam em falha | M14 |
| H12 | Q12 | Disponibilidade observada de pelo menos 95% | M15 |

*Tabela 1: Hipóteses por questão. Fonte: elaborado pela equipe.*

**Como as hipóteses serão julgadas na Fase 4:** a hipótese é **confirmada** se todas as suas métricas ficarem no nível Bom ou acima, **parcialmente confirmada** se a pior ficar em Satisfatório e **refutada** se alguma ficar em Insuficiente (ver [critérios de julgamento](niveis-pontuacao.md#criterios-de-julgamento)).
