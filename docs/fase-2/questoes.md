# Questões

*Nível operacional.* Cada [objetivo](objetivos.md) é desdobrado em questões que caracterizam o seu foco de qualidade. As questões perguntam sobre o comportamento do aplicativo; a forma de medir cada uma está nas [métricas](metricas.md).

| Objetivo | Questão | Enunciado | Métricas |
| :--- | :--- | :--- | :--- |
| O1 | Q1 | Os usuários realizam as tarefas principais com eficácia e eficiência? | M1, M2 |
| O1 | Q2 | Como os usuários percebem a facilidade de aprender e usar o aplicativo? | M3 |
| O2 | Q3 | O aplicativo atende a critérios básicos de acessibilidade? | M4 |
| O3 | Q4 | Em que medida o aplicativo previne e trata erros do usuário? | M5, M6 |
| O4 | Q5 | As funções previstas estão disponíveis no aplicativo? | M7 |
| O4 | Q6 | As funções produzem os resultados esperados? | M8 |
| O5 | Q7 | Saldo, histórico e extrato são coerentes entre si? | M9 |
| O5 | Q8 | O saldo é atualizado no prazo divulgado após a recarga? | M10 |
| O6 | Q9 | O aplicativo responde em tempo adequado, inclusive em rede limitada? | M11, M12 |
| O7 | Q10 | O aplicativo se recupera de interrupções sem perda ou duplicidade de dados? | M13 |
| O7 | Q11 | Com que frequência o aplicativo falha durante o uso? | M14 |
| O8 | Q12 | Os serviços estão acessíveis quando o usuário precisa? | M15 |

*Tabela 1: Questões por objetivo de medição. Fonte: elaborado pela equipe.*

O resultado esperado para cada questão está em [Hipóteses](hipoteses.md).
